# 02 · D120 采购申请按行分批到货

Type: task
Status: ready-for-agent
Blocked by: 01

详见 ADR-0016。Q8 用户拍板：**按行整批到，行内数量不可拆**。

## 范围

### DB
- `biz_purchase_request_detail` 加 `receive_status`（1 待到货/2 本批待入库确认/3 已入库）、`arrive_batch_no`（同批分组，驳回/撤回按批）。
- 头状态复用现有 5 待入库确认；部分入库回到可继续到货态（可用现有 status=2 + 部分行已入库的派生口径，或新增状态值——实现时定并在 ADR 补注；前端文案统一「部分入库」）。

### 后端（PurchaseRequestService）
- arrive 改：入参勾选行 detailId 列表 + 逐行单价；校验勾选行 receive_status=1、数量按申请量整行（不接受拆量）；勾选行置 2、写 arrive_batch_no、头→5。
- confirmReceive：本批行 2→3，调票 01 的 createInternal **一张多行进货单**；仍有行≠3 → 头回部分入库可继续到货；全 3 → 头 3。
- arriveCancel/arriveReject 改为按批：只退本批行回 1，已入库历史批次不动。
- D86 在途守卫口径含部分入库态（全部行入库才放行同生产单再补料）。
- 消息：到货通知一条带本批行数；驳回/撤回归 D21，按批次标题白名单防误撤他批待办。
- 列表/详情 VO 加行级 receive_status、批次分组。

### 前端（PurchaseRequestView）
- 到货提交弹窗：未到货行勾选表（数量只读=申请量、逐行单价、全选未到货行）；明示「同一物料数量不支持分批，请等整行到齐」。
- 详情：各行到货状态列 + 按批次分组；仓储待入库列表展示本批行。
- D104 采购申请时间线「到货/入库」节点按批重复（第 N 批到货→入库）。

### 测试
- 单测：19+1 两批提交（先勾 19 行→确认入库→剩余 1 行再提交→全入）、勾选已入库行被拒、行内拆量被拒、批次驳回只回本批、全入后 D86 守卫放行、消息按批撤发。
- E2E：两批各生成一张多行进货单、库存与进价按行正确。

## 验收
- 部分行先到时先到先入，单号数=到货批次数；同一物料数量不到齐不能提交该行。
