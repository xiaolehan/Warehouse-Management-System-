# 04 · D112 新成品（零库存/无 BOM）销售→生产联动

Type: task
Status: ready-for-agent
Blocked by: 03

Q2=B：主数据先行不放宽；流程通，补标记与一键动线。事实依据：生产下达成品下拉 `hasBom:true` 静默过滤无 BOM 成品是核心断点。

## 范围

### 后端
- 销售建单/详情 VO：每行带 zeroStock（库存 0）与 hasBom 标记（查有效 BOM 存在性，批量 in 查）。
- 缺货消息 sendSalesDemandToProductionAdmins：行描述附「（未建档 BOM，需先在 BOM 管理建档）」；消息 target_route 维持 /business/production-order，query 带 sales_id（前端直达批量下达弹窗用）。
- 票 03 批量下达已承载「无 BOM 行跳过 + 汇总提示建档」，本票不重复。

### 前端
- SalesView 多行编辑器/详情行：零库存橙标「零库存」、无 BOM 红标「无 BOM」，**不拦下单**。
- 生产端：消息中心点击缺货消息 → 跳生产任务单页并**自动打开「按销售单下达」弹窗、预选该销售单**（票 03 弹窗支持 ?salesId= / route query 预选）。
- （可选低成本）任务单手动下达选成品的下拉：无 BOM 成品不再静默消失——若产品决策保留过滤，则在下拉旁加「为何选不到新成品？」提示文案指向 BOM 管理。

### 测试
- 单测：行标记正确；消息文案含无 BOM 提示。
- E2E：建成品不建 BOM → 销售单行双标可提交 → 生产收消息点击直达弹窗见该行被跳过并提示建档。

## 验收
- 新成品销售不需要问「这单怎么写」：照常下单，生产点消息即达排产入口，无 BOM 有明确建档指引。
