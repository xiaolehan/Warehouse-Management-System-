# 03 · D113 按销售单批量下达生产任务单

Type: task
Status: ready-for-agent
Blocked by: 无（但建议在 D111 结构改造后做，避免两个大改交叉）

Q3=A：保持一成品一任务单（ADR-0013 锚点不动），解「多成品单要逐张点」。

## 范围

### 后端（ProductionOrderService/Controller）
- 新增批量创建：入参 sales_order_id + 选择 detail_id 列表（或全选），循环现有单条创建逻辑（BOM 必填校验逐行、齐套计算、kit_status 快照、sales_detail_id 锚定、关联校验 requireLinkableSalesOrder）；
- 同一成品行已有在途任务单（未终态）的行默认不重复生成、结果中标注；
- 返回每行结果（已生成订单号/跳过原因：无 BOM、已有在途单、已生产入库满足数量等）。
- 注意循环里每个订单独立校验：无 BOM 行**跳过不阻断**其他行（不要因一行失败整批回滚正常行——实现方式：逐行 try/catch 收集结果，或预校验后只提交可建行；事务边界按行定，齐套通知等按单正常触发）。

### 前端（ProductionOrderView）
- 列表加「按销售单下达」按钮 → 弹「选销售单（linkableOptions 的多成品版：正常且待出库的销售单）→ 列出全部明细行」两/一屏弹窗：
  每行显示成品名、订单行数量、当前库存、BOM 状态（有/无）、在途任务单（有则展示订单号并禁选）、**预填生产数量=订单行数量**（可改）；
- 提交后结果汇总弹窗：「已生成 PRO…（齐套结果）…；X 个成品无 BOM 已跳过，请先在 BOM 管理建档后单独下达」。
- 列表可按关联销售单号筛选/分组（让「这张销售单的所有任务单」一眼看全）。

### 测试
- 单测：两行都有 BOM → 2 单各锚定 detail；无 BOM 行跳过；已有在途单行跳过；部分成功事务正确；sales_detail_id 锚点正确。
- E2E：销售单 4（PTO153+SMC105）批量下达 2 任务单 → 后续领料/工序/入库链路各自正常（与 D110 E2E 口径一致），测后清理。

## 验收
- 一张 N 成品销售单一次操作生成 ≤N 张任务单；无 BOM 新品不卡其他成品先做。
