# Spec：用户手测十题修复批（D111–D120）

> 2026-09-20 grill-with-docs 两轮定案。决策总账见 findings-d111plus.md；
> 难逆决策见 ADR-0015（进货头行）、ADR-0016（按行分批到货）；词汇见 CONTEXT.md。
> 用户约定：**本批全部改完后与 D105–D110 一起统一手测**（清单 pending-retest.md）。

## 决策摘要（两轮拍板）

| 票 | 编号 | 主题 | 关键决策 |
|---|---|---|---|
| 01 | D111 | 进货单头行改造 | 一单多物料、同物一行；整单作废/删除；采购申请入库合并生成一张多行单；进货退货对称多行化；旧数据迁一头一行 |
| 02 | D120 | 按行分批到货 | 勾选行分批提交，**行内数量不拆**；部分入库态；每批一张多行进货单；批次驳回/撤回 |
| 03 | D113 | 按销售单批量下达 | 保持一成品一任务单，选销售单一键生成 N 张；无 BOM 行跳过不阻断 |
| 04 | D112 | 新成品联动 | 销售行零库存/无 BOM 标记；缺货消息带无 BOM 提示并直达批量下达弹窗 |
| 05 | D114 | 任务单生命周期时间线 | 详情底部合成全动线时间线，工序合并为带进度单节点，终止/作废红色终态 |
| 06 | D115 | 到货备注统一填充 | 认领弹窗加「应用到全部行」，覆盖全部行 |
| 07 | D116 | 齐套口径修订 | 未开工（状态1）列表+详情实时重算，到齐显「齐套」、补料按钮联动消失；2/3 维持；≥4 隐藏 |
| 08 | D117 | 确认收货入口 | 任务单详情领料区加按钮，同 PickList 接口/权限，状态机不变 |
| 09 | D118 | 盘点列表导出 | 列表行操作加「导出」直接下发明盘表；盲盘/导入留详情 |
| 10 | D119 | 来源进货单显示修复 | 查看态改纯文本单号（仓储不再因选项空而显示数字 ID） |

## 建议实施顺序

1. **06/07/08/09/10**（五个小项，互不依赖，可先清场）
2. **01**（结构大改：DDL+迁移+Purchase/PurchaseReturn 重写+统计/引用/时间线适配）
3. **02**（依赖 01 的多行进货单生成）
4. **03 → 04**（04 的一键直达依赖 03 的弹窗）
5. **05**（最后，到货节点要按 02 的批次语义合成）

## 全局验收纪律（CLAUDE.md 之外本批附加）

- DDL 写 db.sql 规范段重写 + 增量段；本地库先执行 ALTER/迁移并验证旧单一头一行。
- 库存只走各业务 Service 私有 increase/decreaseStock；消息遵守 D21（biz 绑定 + 终态撤未读）。
- 每票收尾：后端单测 + `npm run build` + curl/python E2E，测试数据用完即清、库存恢复。
- 本批完成后更新 pending-retest.md「D111+ 联动复测项」，交用户统一手测。
