### 票 01 / D111 进货 + 进货退货头行结构（重点）
1. **多行建进货单**：物料进货新建 → 加多行、选不同物料（同物料重复行被拦截，提示同一物料一单一行）；总数量/总金额实时合计；每行显示当前库存+最近进价；删除行按钮（仅剩一行时禁用）。
2. **到货 → 确认入库**：整单到货后仓储确认，**逐行**加库存；每行单价回写该物料主数据进价；查看详情为头信息+明细行快照表（品名/规格/数量/单价/行金额）。
3. **行级退货**：新建退货选来源进货单 → 按来源明细行展示「原进货/已退/可退」；勾选行、本次退货数 1..可退量（上限钳制、整数）；同一来源行重复选拦截；跨进货单行拦截（提示按进货单分别退货）；超退拦截并提示「最多可退: N」；退款金额按勾选行合计。
4. **退货确认出库**：仓储确认后**逐行**扣库存；退货查看（采购端/仓储端两边一致——D119）：来源进货单号、明细行快照、备注完全相同。
5. **整单作废守卫（新规则）**：进货单存在未终结退货单（哪怕待出库）时，仓储作废进货单被拦截，提示「请先删除或作废退货单」；删除（当天待出库）/作废退货单后再作废进货单成功。
6. **已入库进货单作废**：逐行回冲库存，被作废单若是当前进价来源，各物料进价回退为最近有效批次单价；未入库作废/删除不碰库存。
7. **删除级联**：当天待到货进货单/待出库退货单删除 → 明细行级联软删，无孤立行。
8. **采购申请联动**：生产补料申请（多物料）认领采购、到货入库后生成**一张多物料进货单**（不再每物料一单）。
9. **统计/进价历史**：首页统计、商品详情「进价历史」按明细行聚合正确（一单多物料不重算、不漏算）。

### 票 02 / D120 采购申请按行分批到货（重点）
1. **到货提交弹窗（采购端）**：仅列出未到货行；勾选行 + 逐行采购单价（数量列只读=申请量，不可改）；表头勾选框=全选未到货行；不勾选任何行提交会被拦截；弹窗明示「按行整批到货：同一物料数量不支持分批，请等整行到齐后再勾选该行」。
2. **分批到货 → 每批一张多行进货单**：两行申请单先勾 1 行提交到货 → 头变「待入库确认」；仓储确认后**只对已勾行**生成一张 1 行进货单并逐行加库存，头回「采购中」但显示**「部分入库」**；再提交剩余行 → 确认后第二张进货单，头变「已入库」。多行同批一起提交则生成一张多行进货单。
3. **行状态与批次列**：详情明细行新增「到货批次」（B1/B2…）与「到货状态」（待到货/待入库确认/已入库）列；已入库行批次保留可追溯。
4. **驳回入库 / 撤回到货**：仅重置**本批**行（批次清空、回到待到货、单价保留预填）；已入库历史行不受影响；重新提交后批次号重排仍从 B1 开始。
5. **时间线按批重复**：详情时间线出现「第 B1 批到货 → 第 B1 批入库确认 → 第 B2 批到货 → …」成对节点；未完单时末尾有「继续到货（剩余 N 行）」当前节点。
6. **消息按批收发**：每批到货通知仓储管理员（标题「待确认采购入库」）；该批被确认（全部行入库）/驳回/撤回后对应未读消息按批撤销，不误撤其他批。

### 票 03 / D113 按销售单批量下达生产任务单（重点）
1. **入口与候选**：生产任务单列表 → 「按销售单下达」按钮（仅生产研发部管理员）；下拉仅列正常且待出库销售单（近期 50 张）。

3. **批量下达结果**：提交后结果汇总——成功行「已生成 PRO…（齐套状态）」；无 BOM 行提示「X 个成品无 BOM 已跳过，请先在 BOM 管理建档后单独下达」；在途行/已满足行显示跳过原因。一张 N 成品单一次操作生成 ≤N 张任务单。
4. **锚点验证**：生成的任务单详情关联销售单号=该销售单；列表按「关联销售单」搜索（任务单列表新增筛选框+列）能一次看全这张单的所有任务单。
5. **重复下达拦截**：对同一销售单再次下达 → 在途行提示「已有在途任务单（PRO…）」跳过，不重复生成。
6. **无 BOM 新品不卡单**：含无 BOM 成品的销售单批量下达 → 其他成品行正常生成任务单，无 BOM 行单独跳过（先建档后单独下达即可）。
