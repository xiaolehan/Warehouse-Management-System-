# 05 · D125 工序-质检顺序门禁

Type: task
Status: ready-for-agent
Blocked by: 无

用户定案（第二轮 Q5）：后端强校验+前端解锁（推荐案）。现状：工序打卡完全无顺序约束（工序9 可先于工序1 打），质检不看工序进度随时可录。

工序表（ProductionStepService.PROCESS_STEPS，勿改）：1 磁性材料装配 / 2 底座结构组装 / 3 手柄机构装配 / 4 PCB板焊接及安装 / 5 程序烧录 / **6 首次测试（质检推导，非打卡）** / 7 屏蔽壳安装 / **8 成品测试（质检推导，非打卡）** / 9 发合格证条码标签配件及包装 / **10 成品入库（入库推导，非打卡）**。可打卡步骤 MANUAL_STEP_NOS=[1,2,3,4,5,7,9]。

## 门禁表

1. 工序 1-5 全部打卡 → 解锁「首次测试」（QcService 首测录入）
2. 首测**最新一次**合格 → 解锁工序 7 打卡
3. 工序 7 打卡 → 解锁「成品测试」
4. 成品测**最新一次**合格 → 解锁工序 9 打卡

- 工序 1-5 内部不限定先后；工序 10 不受影响（入库推导）；工序 6/8 的 done 状态继续由质检记录推导。
- 「最新一次合格」口径：NG→返工→重测合格即解锁；最新一次为 NG 则保持锁定。

## 范围

### 后端
- ProductionStepService.complete：按门禁表校验，不满足 BusinessException（文案指明缺什么，如「首次测试尚未通过，无法打卡屏蔽壳安装」）。
- QcService.record：首测校验 1-5 全打卡；成品测校验工序 7 已打卡（质检页提交同样被拦）。
- revoke：撤销不得使已发生的门禁失效——已存在首测记录时禁撤工序 1-5；已存在成品测记录时禁撤工序 7；工序 9 在订单离开生产中（待入库/已完结/终态）后禁撤。
- 列表 VO 透出门禁状态（步骤 operable 纳入门禁；质检页列表 VO 增 首测/成品测解锁标记），前端零自行推断。

### 前端
- ProductionOrderView 工序表：仅解锁步骤显示「打卡」（锁定步骤灰置+提示文案/tooltip）。
- QcView：未解锁测点禁选（下拉禁用+原因提示），解锁后可选。

### 测试
- 单测：门禁表四条正/反（打卡越序拒、质检提前拒）；返工重测解锁；撤销保护三条；门禁放行后正常打卡/质检不受影响。
- E2E：跑一条 1-5 打卡→首测 OK→7 打卡→成品测 OK→9 打卡→两段式入库全链，中途越序负测。

## 验收
- 生产端照门禁顺序操作无感；越序操作前后端都被拦且提示明确为什么不能点。
