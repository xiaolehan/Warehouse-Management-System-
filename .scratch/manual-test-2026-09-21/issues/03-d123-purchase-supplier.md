# 03 · D123 进货单记录供应商 + 物料最新供应商

Type: task
Status: ready-for-agent
Blocked by: 无

用户定案（第二轮 Q3）：进货单记供应商（推荐案）。现状：采购/进货单据完全不记录供应商，仅物料资料绑一个「所属供应商」（默认供应商，人工维护，D109 靠到货备注文本匹配）。

## 范围

### 数据库
- `biz_purchase` 加头级 `supplier_id`（可空——存量单无值）；db.sql 规范段 + 增量段，本地执行。

### 后端
- 进货单创建（D111 多行头结构）DTO/Service 增 supplierId **必填**校验（须为有效供应商）。
- 进货退货：不新增录入，供应商从来源进货单带出仅展示。
- 物料「最新供应商」：GoodsVO 增 latestSupplierName——该物料最近一次**已入库**（confirm_status=3）正常（biz_status=1）进货单的供应商名（批量查询防 N+1，复用 latestValidUnitPrices 的查询范式）；无进货记录回退物料绑定 supplierName。仅物料（type=material）计算，成品不显示。

### 前端
- 进货录入弹窗加「供应商」必填选择器（供应商 options 接口已存在）。
- 物料管理列表「所属供应商」列升级为「最新供应商」（有进货记录显示最新，无则显示默认绑定并可加「默认」小标）；详情同步。
- 进货单详情/列表展示供应商列。

### 测试
- 单测：创建缺供应商拒绝；最新供应商口径（最近已入库单优先、回退默认绑定、作废单不参与）；退货带出来源供应商。
- E2E：录两张不同供应商进货单→物料最新供应商切换正确；清理恢复。

## 验收
- 同一物料换了供应商进货后，物料信息里最新供应商自动更新，无需人工维护。
