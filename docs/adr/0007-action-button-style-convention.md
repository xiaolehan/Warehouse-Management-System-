# ADR-0007: 全站操作栏按钮风格规范（以商品资料管理页为基准）

> 状态：accepted（2026-09-11 会话 29，grilling 8 题定案 + to-spec 留档 `.scratch/button-style-unification/spec.md`）

## 背景

全站 23 个列表页的按钮风格各自为政：操作列按钮有实心 / link / text 三种形式并存，有的带图标有的不带，进货/销售系列用 `.action-group` 纵向堆叠（行高不一、按钮跨行不在同一水平线），有的缺 `size="small"`；工具栏有的缺图标，「新建退货单」用 warning 而其他新增按钮用 success。用户要求全站向「商品资料管理」（物料管理）页看齐，并要求操作列按钮同行不换行、跨行同列对齐。

备选方案：
- **抽共享操作列/工具栏组件**：各页操作列按钮均按行状态 + 权限条件渲染，逻辑差异大，抽组件收益低风险高，且不符合本仓库「每页自持」惯例；
- **el-config-provider + 全局 CSS 强制覆盖**：改不了形式（实心↔link）、去不掉图标、改不了纵向布局，且影响面不可控；
- **逐页显式改属性 + 全局沉淀一小段不换行 CSS**（采纳）。

## 决策

### 三类位置规范（基准 = GoodsView 商品资料管理页）

1. **顶部工具栏**：实心按钮、默认大小（不写 size）、带图标。查询 `primary`+Search / 重置 默认+Refresh / 新增类 `success`+Plus。
2. **表格操作列**：`link` + `size="small"` + 无图标 + 水平平铺，按钮间无分隔符（EP 默认 12px 相邻间距）。列必须设固定 `width`（按「单行同时可出现的最宽按钮组合」计算，含 v-permission 禁用态仍占位），并 `fixed="right"`。
3. **对话框底部**：取消在左（默认+Close）、确认在右（`primary`+Check）。

### 颜色语义映射（全站唯一约定）

| 动作类别 | type |
|---|---|
| 查看 / 详情 / 普通操作（认领、导出、修改到货计划等） | primary |
| 编辑 / 修改 | success（跟基准页，编辑就是绿色） |
| 流程动作 / 确认类（确认入库/出库、到货确认、发料、开工、质检、审批通过） | success |
| 警示非毁灭（作废 / 驳回 / 补料 / 撤回到货） | warning |
| 不可逆危险（删除 / 红冲 / 终止 / 撤销本人单据） | danger，永远排在操作列最后 |

### 排列顺序

查看/详情 → 流程动作（按业务流转顺序）→ 编辑/修改 → warning 类 → danger 类（置尾）。

### 不换行机制

`assets/main.css` 全局一条：`.el-table .cell:has(.el-button) { white-space: nowrap; }`——兜底保险；真正保证不换行的是每页操作列按最宽组合设定的固定 width。新页面接入时二者都要做。

## Consequence

- 新增列表页/操作列必须遵守本规范（形式、语义色、顺序、固定宽 + nowrap）；评审新页面时按上表核对。
- 危险操作保留红色是防误触安全线，「颜色统一」不适用于抹掉 danger 语义。
- 对话框内表单辅助按钮（添加明细行、删除联系人、上传图等）、详情页主操作、消息中心、布局头部、首页卡片不受本规范约束。
- 「编辑=绿色 success」是基准页既定现状，全站跟随；如未来要改语义色，需全站一起改并修订本 ADR。
- `.action-group`（进货/销售/生产 5 页）已改为水平 flex，依赖 EP 默认相邻间距，不再自定义按钮 margin。
