# ADR-0020: 成品拆分单 — 独立单据承载「成品出库→生产拆解→物料退库」

日期：2026-10-02　|　状态：已采纳　|　关联：ADR-0019（行终止）、D107（成品入库两段式）、D73（手动终止）、ADR-0007（前端规范）

## 背景

销售明细行终止（ADR-0019）时，若该行成品已生产入库但销售单尚未确认出库，仓库里会留下
「已入库未出库」的成品。此前系统对此没有任何出口：成品滞留仓库库存，既不能当正常现货卖
（需求已取消），也没有任何机制把它拆解回物料。需求四（会话 62 grilling 定稿）要求仓储在
履约进度里二选一：**保留成品**（留痕+回执生产）或 **发起成品拆分**（把成品出库给生产拆解，
物料退回仓库）。

## 决策

1. **新建独立单据「成品拆分单」（biz_split_order），不复用生产任务单。**
   生产任务单无法承载：状态机不同（拆分是仓储发起、跨部门接力，与生产排产无关）、
   已终止单无法重开、RETURN 退料上界校验（已领未退）不适用于拆解产出。
2. **状态机（7 态）**：1 待生产领取 → 2 待仓储确认成品出库 → 3 待生产确认收货 →
   4 拆分中 → 5 已完成；旁支：7 待仓储确认成品回库（生产放弃拆分，走 D107 两段式
   精神：仓储确认回库才加库存）→ 5 已完成（完成方式=放弃回库）；6 已作废（仓储作废，
   仅限未动库存的 1/2 态）。
3. **物料需求快照 = BOM×拆分数量**（发起时定格为 `biz_split_order_detail`），实际退料
   走既有领料单模块 RETURN 类型（biz_pick_list.type=RETURN，新增 `split_order_id`
   关联列；production_order_id 置空），退料行差异备注复用 Q16 差异机制。
4. **生产侧操作者口径 = 领取人本人或生产管理员**（对齐工序打卡撤销口径）；
   仓储侧写操作 = 仓储管理员。
5. **触发口径**：仅销售**行终止**通道（一期）在「已入库未出库量>0」时通知仓储并在
   履约进度行上出双按钮；销售单整单删除/作废/冲抵通道**一期不触发**（显式范围收缩，
   后续票可扩）。处置留痕落在 `biz_sales_detail.split_status/split_order_id/split_keep_*`。
6. **消息全部按 D21 范式**绑 biz（拆分单生命周期消息绑 `split_order`；行处置通知绑
   `sales_detail_split`，在保留/发起拆分时撤销，拆分单作废回退待处理时重发）。

## 后果

- 正向：跨部门拆分流程有独立留痕与状态机；物料回流复用 RETURN 收料闸（仓储确认才
  加库存）；成品回库复用两段式精神（仓储确认才加库存）；历史行终止数据兼容
  （split_status 为空的已终止行按实时计算回填按钮口径）。
- 负向：新增一张头表+一张明细表与一个新页面；RETURN 单据主体归属领料模块但语义上
  属于拆分单（通过 split_order_id 关联，列表需标注「拆分退料」）。
- 放弃拆分后成品回库不生成独立回库单据，以拆分单「放弃回库」终态承载（一期从简）。
